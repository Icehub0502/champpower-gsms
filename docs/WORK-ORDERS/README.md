# ใบสั่งงาน (Work Orders)

ตัวเชื่อมระหว่าง **Cowork** กับ **Claude Code ในเครื่อง**

```
คุณ  →  Cowork            →  Claude Code ในเครื่อง  →  Agent 9 ตัว
        ออกแบบ ตัดสินใจ       รัน เขียนไฟล์ เทส          ลงมือเฉพาะทาง
        เขียนใบสั่งงานลงที่นี่   อ่าน CLAUDE.md เอง         ผ่านเกตรีวิว
        ตรวจงานที่เสี่ยง
```

## วิธีใช้

1. Cowork เขียนใบสั่งงานไว้ที่โฟลเดอร์นี้ (`WO-001`, `WO-002`, …)
2. เปิด Claude Code ที่ `C:\dev\gsms` แล้วพิมพ์ประโยคเดียว:

   ```
   อ่าน docs/WORK-ORDERS/WO-001-auth-hardening.md แล้วทำตามนั้น
   ```

   มันจะอ่าน `CLAUDE.md` เองอัตโนมัติ แล้วส่งต่อให้ `gsms-lead` แจกงาน
3. ทำเสร็จแล้วเอาสรุปที่มันรายงาน มาวางใน Cowork เพื่อให้ตรวจ

## ก่อนใช้ครั้งแรก

ดับเบิลคลิก `install-agents.bat` ที่ root — จะก๊อป `docs/agents/*.md` เข้า `.claude/agents/`
ให้ Claude Code มองเห็น agent ทั้ง 9 ตัว (Cowork เขียนลง `.claude/` เองไม่ได้)

## อะไรทำที่ไหน

| ทำที่ Cowork | ทำที่ Claude Code |
|---|---|
| ออกแบบโครงสร้าง ตัดสินใจเรื่องธุรกิจ | เขียนโค้ดตามใบสั่งงาน |
| เขียน/แก้ `CLAUDE.md` และเอกสารออกแบบ | รันเทส รัน migration ดีบัก |
| ตรวจงานที่แตะ **เงิน · สต๊อก · ภาษี · สิทธิ์** | งานประจำวัน หน้าจอ route |
| ตัดสินเรื่องที่ผิดแล้วแก้ยาก | งานที่ผิดแล้วเห็นทันทีจากเทส |

**กฎเดียวที่ห้ามละเมิด: คนเขียนกับคนตรวจต้องไม่ใช่คนเดียวกัน**
WO-001 เกิดขึ้นเพราะ Cowork เขียนชั้น auth แล้วตรวจเอง — มองข้ามช่องโหว่ 15 ข้อ
รวมถึงสองข้อที่ทำให้ระบบยกเลิกสิทธิ์พนักงานที่ลาออกไม่ได้เลย
